# Домашнее задание 11 - Stream API

## Описание проекта

Разработала консольное приложение на Java для работы с данными об автомобилях с использованием Stream API. Программа читает данные из файла, обрабатывает их и выводит результаты выполнения четырех задач.

## Что делала в процессе работы

1. **Изучала Stream API** - разбиралась с методами filter(), map(), collect(), sorted(), distinct()
2. **Создала структуру проекта** согласно требованиям задания
3. **Реализовала класс Car** с полями: номер, модель, цвет, пробег, стоимость
4. **Написала репозиторий** для работы с файлами (чтение и запись)
5. **Решила 4 задачи** с использованием Stream API:
    - Поиск автомобилей по заданному цвету или нулевому пробегу
    - Подсчет уникальных моделей в определенном ценовом диапазоне
    - Поиск цвета самого дешевого автомобиля
    - Расчет средней стоимости по указанной модели
6. **Настроила работу с файлами** - данные хранятся в data/cars.txt
7. **Протестировала программу** на корректность работы

## Использованные технологии

- **Java 17** - язык программирования
- **Stream API** - для обработки данных
- **IntelliJ IDEA** - среда разработки
- **Git** - система контроля версий
- **GitHub** - хостинг репозитория

## Решаемые задачи

1. Поиск номеров автомобилей по цвету "Black" или нулевому пробегу
2. Подсчет уникальных моделей в ценовом диапазоне 700-800 тыс.
3. Определение цвета автомобиля с минимальной стоимостью
4. Расчет средней стоимости для моделей Toyota и Volvo

# 💻 JavaCourse — тренировочный репозиторий

Этот репозиторий создан для прохождения обучающего курса по Java.  
Содержит тренировочные примеры, домашние задания, а также точку входа в программу.

---

## 📂 Структура проекта
<pre lang="markdown">

├── homework3

└── train

</pre>
---

## 🚀 Запуск

Для запуска программы:

1. Открой `Main.java` (путь: `ru.rt.start.Main`)
2. Нажми ▶ или выполни `Run 'Main'`

---

| Папка/файл                  | Назначение                        |

## ✅ Цель

- Практиковаться в написании кода на Java
- Научиться организовывать проектную структуру
- Освоить синтаксис, ООП и работу с IDE (IntelliJ IDEA)

---

## 📌 Примечания

- Проект использует JDK 21 (`Eclipse Adoptium`)
- Среда разработки: IntelliJ IDEA Community Edition
- Без фреймворков, чистый Java

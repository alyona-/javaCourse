# Описание проекта: Покупки

## Цель

Реализовать консольное приложение для ввода списка покупателей, товаров и покупок, а затем выводить результаты: кто что купил.

## Структура

* **App** — точка входа, отвечает за организацию работы: ввод, обработка и вывод.
* **Person** — модель покупателя. Хранит имя, сумму денег и список купленных товаров. Использует `toString()`, `equals()`, `hashCode()`.
* **Product** — модель товара. Состоит из названия и цены. Использует `toString()`, `equals()`, `hashCode()`.

## Логика работы и архитектура

### 1. `App`

Отвечает за организацию взаимодействия между пользователем и моделями:

* **`readPeople()`** — считывает покупателей из ввода. Вызывает `Person.parse()` для разбора строки. Обрабатывает исключения.
* **`readProducts()`** — считывает продукты. Использует `Product.parse()`.
* **`processPurchases()`** — организует процесс покупок. Проверяет, существуют ли покупатель и продукт. Вызывает `buy()` у покупателя.
* **`printResults()`** — выводит итоги, используя `person.toString()`.

### 2. `Person`

* Поля `name`, `money`, `products` (список `Product`).
* Сеттеры с валидацией: имя не пустое, не короче 3 символов. Деньги — неотрицательные.
* Метод `buy(Product)` — проверяет возможность покупки и обновляет состояние.
* Метод `parse(String)` — разбирает строку "Имя = Сумма" и возвращает объект.
* `toString()` — возвращает строку вида: "Имя - Товар1, Товар2" или "Имя - Ничего не куплено".
* `equals()` и `hashCode()` — на основе `name`, для использования в `Map`.

### 3. `Product`

* Поля `name`, `price`. Сеттеры с валидацией.
* Метод `parse(String)` — разбирает строку "Товар = Цена".
* `toString()` — возвращает строку: "Название (цена)".
* `equals()` и `hashCode()` — на основе `name` и `price`.

## Использование `toString()`

Метод `toString()` используется вместо отдельного метода `showPurchases()`. Это упрощает код, позволяя напрямую выводить `System.out.println(person)`, не нарушая инкапсуляции.

## Использование `equals()` и `hashCode()`

Эти методы переопределены, чтобы объекты `Person` и `Product` можно было корректно использовать в `Map`, `Set`, сравнениях и при возможной сериализации.

## Использование `parse()`

Методы `parse()` в `Person` и `Product`:

* Инкапсулируют разбор строки.
* Делают `App` чище.
* Переносят логику ближе к данным (по принципу SRP).

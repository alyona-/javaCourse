# Homework 11 - Java Stream API и работа с файлами

Этот проект реализует работу с автомобилями через Java Stream API и файловые операции.

## Структура проекта

### data/cars.txt
Файл с исходными данными об автомобилях в формате:
`номер|модель|цвет|пробег|стоимость`
- Создан вручную для хранения тестовых данных
- Данные читаются и обрабатываются программой

### src/model/Car.java
Класс модели автомобиля с полями:
- number - номер автомобиля
- model - модель автомобиля
- color - цвет
- mileage - пробег
- cost - стоимость

Реализованы:
- Конструктор с параметрами
- Геттеры и сеттеры для всех полей
- Метод toString() для красивого вывода
- Методы equals() и hashCode() для корректной работы коллекций

### src/repository/CarsRepository.java
Интерфейс репозитория с методами:
- findAll() - получить все автомобили
- saveAll() - сохранить все автомобили
- findByColorOrMileage() - найти по цвету или пробегу
- countUniqueModelsInPriceRange() - подсчитать уникальные модели в диапазоне цен
- findCheapestCar() - найти самый дешевый автомобиль
- calculateAverageCostByModel() - посчитать среднюю стоимость по модели

### src/repository/CarsRepositoryImpl.java
Реализация репозитория с работой с файлами:
- Чтение данных из файла cars.txt
- Запись данных в файл
- Обработка ошибок ввода-вывода
- Реализация всех методов через Stream API

### src/Main.java
Главный класс программы, который:
- Инициализирует репозиторий
- Читает данные из файла
- Выполняет 4 задачи через Stream API
- Выводит результаты в консоль


## Как запустить
1. Клонировать репозиторий
2. Перейти в ветку homeworks/homework011Addition
3. Скомпилировать и запустить Main.java
4. Программа прочитает данные из data/cars.txt и выведет результаты

## Решаемые задачи
1. Поиск автомобилей по цвету или нулевому пробегу
2. Подсчет уникальных моделей в ценовом диапазоне
3. Поиск цвета самого дешевого автомобиля
4. Расчет средней стоимости по моделям

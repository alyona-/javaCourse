# 🧾 Product App — Итоговая аттестация по курсу Java

Проект выполнен в рамках **итоговой аттестации курса "Java-разработчик"**.  
Приложение демонстрирует работу с базой данных PostgreSQL через **JDBC**  
и управление схемой с помощью **Flyway**.

---

## 📁 Структура проекта
```
src/
└─ main/
├─ java/org/example/App.java          → основной класс приложения  
└─ resources/
├─ application.properties         → настройки подключения к БД  
├─ simplelogger.properties        → конфигурация логирования  
├─ db/
│   └─ migration/
│       ├─ V1__init_schema.sql    → создание таблиц (DDL)
│       └─ V2__insert_data.sql    → заполнение таблиц начальными данными (DML)
└─ sql/
├─ schema.sql                 → ручное создание схемы (для проверки задания №2)
└─ test-queries.sql           → SQL-запросы и обновления (задание №3)
```
---

## 🚀 Что делает программа

1. Загружает настройки из `application.properties`.
2. Подключается к базе данных PostgreSQL.
3. С помощью Flyway:
    - очищает схему (`clean`);
    - применяет миграции `V1__init_schema.sql` и `V2__insert_data.sql`.
4. Через JDBC:
    - вставляет тестового покупателя и товар;
    - фиксирует транзакцию в БД (`commit`);
    - выводит результат в консоль.

---

## 🧩 SQL для ручной проверки

Файлы в папке **src/main/resources/sql/** предназначены для **ручной проверки заданий**  
(выполняются напрямую в СУБД без запуска Java-кода):

- `schema.sql` — создание таблиц вручную (DDL, задание №2);
- `test-queries.sql` — выборки и обновления (задание №3).

---

## ⚙️ Используемые технологии

- **Java 17**
- **PostgreSQL 12+**
- **Flyway 10.16**
- **JDBC**
- **Maven**
- **SLF4J Simple Logger**

---

## 💬 Запуск приложения

mvn clean compile exec:java

Программа автоматически:
- создаёт схему и накатывает миграции;
- добавляет тестовые данные;
- выполняет проверочные операции;
- выводит результаты в консоль.
